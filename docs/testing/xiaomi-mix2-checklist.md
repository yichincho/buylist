# 小米 MIX 2 實機驗收清單

版本：0.2.2（沿用不衝突安裝 ID）
APK：`SmartShopping-v0.2.2.apk`
最低系統：Android 7.0（API 24）

## 安裝

1. 在手機「設定 → 更多設定 → 隱私 → 安裝未知應用程式」允許檔案管理器安裝 APK。
2. 將 `app-debug.apk` 傳到手機後點擊安裝。
3. APK 使用本次建置環境的 debug 簽章。若舊版簽章不同，Android 不允許覆蓋安裝；卸載會刪除手機內的清單資料與圖片。使用者提供的 ZIP 沒有舊簽章金鑰，因此先保留舊 App，確認安裝方式前不要卸載。

若以相同簽章升級 v0.2.1，請確認原清單資料已遷移至「v0.2.1 匯入清單」。

## v0.2.2 新增驗收案例

修改前基準：v0.2.1 只有單一清單；輸入框沒有「清除文字」或「加入清單」；AI 與截圖辨識會取代既有品項；沒有清單歷史與整張清單清除。

| 項目 | 操作 | 預期結果 | 修改前基準 |
|---|---|---|---|
| 清除文字 | 在輸入框輸入多行文字，再按「清除文字」 | 只清空輸入框，已加入品項與圖片仍保留 | 沒有清除文字按鈕 |
| 文字加入 | 先有一筆品項，再輸入多筆文字並按「加入清單」 | 新品項接在原品項後方；重複名稱照樣保留；加入後輸入框清空 | 沒有純文字加入按鈕；AI 會取代舊品項 |
| 清單隔離 | 兩張清單分別加入品項及圖片，來回切換 | 每張清單只顯示自己的品項和圖片 | 沒有多清單 |
| 背景作業目標清單 | 在清單 A 開始截圖辨識或圖片匯入，完成前切換到清單 B | 結果仍寫入清單 A，清單 B 畫面不被覆蓋 | 原版沒有多清單，無法測試 |
| 儲存並開新清單 | 在目前清單加入文字及圖片後按「儲存並開新清單」 | 舊清單可從歷史開啟；新清單沒有舊內容 | 沒有儲存新清單按鈕 |
| 清除整張清單 | 對目前含已勾選、未勾選品項及圖片的清單執行清除 | 確認後只清除此清單的品項和圖片；其他清單不變 | 只能清除已完成的項目 |
| 刪除歷史清單 | 刪除一張非目前清單，再刪除目前清單 | 需確認；其他清單保留；刪除目前清單後自動建立空白清單 | 沒有清單歷史或刪除功能 |
| AI 預設服務 | 開啟設定頁 | 預設選取 Gemini，顯示 gemini-3.1-flash-lite | 只有 DeepSeek |
| Gemini 金鑰保存 | 輸入自己的 Gemini Key，儲存、離開設定再返回 | Key 遮罩且仍可讀取；重新開啟後可測試連線 | 只有單一 DeepSeek 金鑰欄位 |
| 提供者金鑰隔離 | 分別儲存 Gemini 與 DeepSeek Key，再清除其中一個 | 清除只影響目前提供者；另一個仍可使用 | 沒有提供者切換 |
| 舊 DeepSeek 金鑰遷移 | 從 v0.2.1 升級後切換至 DeepSeek | 舊加密金鑰仍可讀取並測試 | 無 Gemini 提供者 |
| v0.2.1 資料遷移 | 使用相同簽章升級舊版 | 原品項、完成狀態、圖片、草稿和 DeepSeek Key 均可讀取 | 單清單資料庫 |
| 圖片加文字合併 | 先匯入/辨識一張截圖，再清除輸入框並貼上第二人的文字加入 | 兩次品項都留在同一清單，第二次不覆蓋第一次 | AI 結果會取代舊品項 |
| 無 Key／離線加入 | 清除 Gemini Key 或關閉網路，輸入多筆文字按「加入清單」 | 本機解析成功，先前內容保留 | 沒有純文字離線加入 |
| 無效 Gemini Key | 輸入無效 Key 後執行文字整理 | 顯示可理解錯誤並使用本機解析；不閃退 | 僅支援 DeepSeek |
